# Customtkinter_aulinhas


# 🎨 Estudo & Exercícios: CustomTkinter em Python

Repositório dedicado ao armazenamento de códigos, exercícios e projetos desenvolvidos ao longo do **Curso de CustomTkinter** no YouTube.

## 📌 Sobre o Projeto

O objetivo deste repositório é documentar a minha evolução prática na construção de interfaces gráficas modernas e responsivas utilizando **Python** e a biblioteca **CustomTkinter**. 

Acompanho as aulas através da playlist:
🔗 **[Curso de CustomTkinter no YouTube](https://youtube.com/playlist?list=PL6KTZQDPGs5gZYtK9YblxA-Te9wQM8mdb&si=fwCejABRbmMVeIol)**


## 🛠️ Tecnologias Utilizadas

* **[Python 3.x](https://www.python.org/):** Linguagem base para lógica de programação.
* **[CustomTkinter](https://github.com/TomSchimansky/CustomTkinter):** Wrapper do Tkinter para a criação de UIs modernas.
